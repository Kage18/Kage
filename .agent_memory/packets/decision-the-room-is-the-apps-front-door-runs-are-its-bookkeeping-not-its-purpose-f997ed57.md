# The room is the app's front door; runs are its bookkeeping, not its purpose

> Driving AO's actual Orchestrator not just screenshots showed the design flaw in v6/v7 pre: Kage's app organized aroun…

Driving AO's actual Orchestrator (not just screenshots) showed the design flaw in v6/v7-pre: Kage's app organized around processing machine output (Inbox/Board/Receipts) with the conversational manager (kage room, already built — askManager, MANAGER_CONSTITUTION, the delegation MCP toolset) absent from the app entirely, reachable only via CLI. AO's whole app is one primitive: a live conversation with an orchestrating intelligence, present on first run; the board is a byproduct of that conversation, not a parallel surface. Kage now mirrors that shape while keeping its actual differentiator: the room talks to the SAME manager `kage room` launches (mcp/delegation/manager-client.ts askManager, one MCP surface, one constitution) — dispatch, judgment and reporting happen by talking — but its replies are grounded in kernel-verified receipts, not the agent's own word, and the manager's own prose has restated card numbers stripped by guardManagerProse before the user sees them. Backend: mcp/delegation/room-history.ts persists turns to .agent_memory/room/history.json (askManager is one-shot per call — claude -p has no server session to resume — so continuity comes entirely from this file, replayed as the last 8 turns via composePrompt). mcp/delegation/api.ts adds GET /room, POST /room/message (202 Accepted; the "you" turn persists synchronously before the manager is even asked, so a page reload never loses what you typed), and a RoomState {pending: number, chain: Promise} per daemon — pending is a COUNTER not a boolean, because a boolean flipped by whichever of two queued turns finishes first would report "idle" while a later turn is still running (caught by a test before shipping). SSE gained a second event kind, "room", whose payload DOES carry live text deltas (unlike run events, which are pure {run_id, seq} notifications) — but the persisted /room GET is still the only truth; a missed delta only skips a typing-animation frame, checked by an explicit test. handleDelegationRoute takes an optional askManagerFn override so route tests inject a fake manager instead of shelling out to a real claude/codex CLI (which costs tokens and is slow) — the existing manager-client tests already only exercised pure functions for the same reason. Frontend: app-html.ts's segmented control reordered to Room(1)/Inbox(2)/Runs(3)/Board(4), Room the default view; the "New run" modal stays as a deliberate fast-path (mirrors AO's board offering both "Orchestrator" and "+ New task" side by side) rather than being replaced.
Evidence: 20 new/updated tests in delegation-api.test.ts (empty room, token guard, accept-then-reply-lands, history round-trips into the manager's prompt excluding the just-sent message, two-queued-turns busy-counter correctness, manager failure surfaces as a visible kage turn, SSE room deltas carry text but /room stays the truth). Live end-to-end proof in the browser: sending a message through the real UI hit the real askManager, which spawned a real claude subprocess, which failed with an actual OAuth expiry (reproduced identically by a bare `claude -p` outside Kage) — and the error rendered as a correctly-styled turn in the transcript instead of vanishing, proving the full pipeline including its error path.
Verified by: npm test --prefix mcp → 476 unit + 12 dogfood pass; live Electron shell + browser screenshots against the Kage repo's own daemon

## Verification

20 new/updated tests in delegation-api.test.ts (empty room, token guard, accept-then-reply-lands, history round-trips into the manager's prompt excluding the just-sent message, two-queued-turns busy-counter correctness, manager failure surfaces as a visible kage turn, SSE room deltas carry text but /room stays the truth). Live end-to-end proof in the browser: sending a message through the real UI hit the real askManager, which spawned a real claude subprocess, which failed with an actual OAuth expiry (reproduced identically by a bare `claude -p` outside Kage) — and the error rendered as a correctly-styled turn in the transcript instead of vanishing, proving the full pipeline including its error path.

# Phase 0 truth cleanup: per-citation gate, honest receipts, 4 deps, version lockstep

> Phase 0 truth cleanup 2026 08 11 made public claims match code. 1 Strict write gate is now per citation: capture reje…

Phase 0 truth cleanup (2026-08-11) made public claims match code. (1) Strict write gate is now per-citation: capture rejects when ANY cited path is missing, not only when all are missing; allow_missing_paths stays the escape hatch, and new unresolvedNamedSymbols warns when camelCase/snake_case identifiers in the memory text appear in no cited file, recording quality.unresolved_symbols. (2) Honest receipt v1: recallTokensSaved caps each cited file at RECALL_READ_TOKENS_CAP_PER_FILE (1500 tokens) instead of charging full byte weight (was inflating ~165K tokens per recall on this repo); kage_context and kage_recall receipts lead with observed counts (recalls served, stale withheld) and label token figures as est.; kage gains prints the estimator methodology line. (3) The three dependency was removed (vestigial: only a dead /vendor/three/ daemon route referenced it) so runtime deps are 4, and README plus CONTRIBUTING now say four runtime deps with zero-dependency retrieval instead of zero dependencies. (4) Version lockstep: server.json and both plugin manifests were 2.x while npm was 3.1.0; all bumped to 3.1.0 and release.test.ts now fails on any future drift. (5) Benchmark honesty: R@5 96.17 headline replaced by R@10 98.72 across README, stats SVG, and all 8 translations because the own benchmark table shows plain BM25 ahead on R@5; tests badge updated 340+ to 360+ (actual 363+12).
Verified by: npm test after changes: 363 unit + 12 dogfood pass, 0 fail

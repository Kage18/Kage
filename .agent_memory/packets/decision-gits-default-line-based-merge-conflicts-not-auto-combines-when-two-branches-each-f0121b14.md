# git's default line-based merge CONFLICTS, not auto-combines, when two branches each app...

> git's default line based merge CONFLICTS, not auto combines, when two branches each append exactly one new line to th…

git's default line-based merge CONFLICTS, not auto-combines, when two branches each append exactly one new line to the end of the same existing file — verified by direct git merge reproduction. An append-only journal needs the built-in `merge=union` git attribute (no custom driver script required) for concurrent branch appends to actually merge cleanly.

Learned while delivering: P1b — packet status changes become append-only. Today supersede, stale marking, and reverify grounding-refresh REWRITE packet frontmatter in place across many files — the rewrite class that merge-conflicts. Change: (1) introduce an append-only status journal under .agent_memory (e.g. journal/events-YYYYMM.jsonl, committed) where each record is {at, packet_id, kind: superseded|stale|reverified|restored, fields...} with a unique id; (2) every code path that today rewrites packet metadata (kage supersede, reverify --packet, stale flips from refresh, gc) APPENDS an event instead and leaves the packet file byte-identical; (3) every reader that consumed the rewritten metadata (recall staleness/withholding, kage gc, stale triage, pr check, the viewer) applies the journal overlay at load — one loader function, shared, so read-time truth = packet + latest events; (4) migration: existing already-rewritten packets stay as they are (their current frontmatter is the baseline; the journal starts empty — no rewrite of history); (5) concurrent appends from two branches merge trivially (distinct lines, distinct files by month) — add a test that two journals with interleaved events merge cleanly via git and the overlay result is order-independent for non-conflicting packets and last-write-wins by timestamp for the same packet; (6) keep OKF conformance: a packet plus its events must still export as a valid OKF concept (export applies the overlay). The suite and dogfood tests stay green; kage gc and kage stale keep working through the overlay. Cite files individually; this is the biggest kernel change of the phase — keep the diff within budget by touching only the status-mutation and status-read paths, not capture.

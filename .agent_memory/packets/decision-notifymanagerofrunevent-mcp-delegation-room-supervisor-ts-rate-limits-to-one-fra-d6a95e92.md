> notifyManagerOfRunEvent mcp/delegation/room supervisor.ts rate limits to one frame per run per 30s regardless of whic…

notifyManagerOfRunEvent (mcp/delegation/room-supervisor.ts) rate-limits to one frame per run per 30s regardless of which state the new event carries (lastRunEventByKey keys only on run+session, not run+session+state-change-type) — a review verdict fired immediately after the run's own 'ready' wake for the same run can be silently dropped by this window. It is NOT dropped for a different run, and coalesceGoalEvents/drainPendingGoalEvents still picks up a dropped one on the next idle drain since the durable pending-event log is written before the rate-limit check runs.

Learned while delivering: MCP tool surface + manager prompt for the reviewer role: new kage_review_run tool, manager constitution update describing the review gate, MANAGER_ALLOWED_TOOLS addition, room-supervisor wake-event extension for the new states.

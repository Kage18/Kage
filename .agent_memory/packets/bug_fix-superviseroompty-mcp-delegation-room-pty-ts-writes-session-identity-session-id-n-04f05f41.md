# superviseRoomPty (mcp/delegation/room-pty.ts) writes session identity (session_id + nat...

> superviseRoomPty mcp/delegation/room pty.ts writes session identity session id + native transcript path via writeRoom…

superviseRoomPty (mcp/delegation/room-pty.ts) writes session identity (session_id + native_transcript_path) via writeRoomSessionMeta BEFORE it ever opens its control socket (server.listen happens later) — so by the time a caller's isRoomPtyLive/attachRoomPty can succeed at all, the identity should normally already be on disk; the pre-existing 'hasn't recorded its identity yet' deflection was guarding a narrow startup-race window, not a structural ordering gap.

Learned while delivering: Chat must be first-class even when a thread is pty-bound — two views, one orchestrator. Live repro today: with a room pty alive, a Chat message returns the 182-char paraphrase turn 'Kage sent your message to the terminal session, but hasn not recorded its identity yet... check the Terminal tab for the real reply' — a deflection instead of an answer — and pty-leg replies never carry the new kage-actions payload. Fix in the pty leg (resolvePtyReply in mcp/delegation/api.ts + room-transcript.ts + room-pty.ts as needed): (1) when a chat message routes to the pty, extract the manager's ACTUAL reply text from the native transcript (room-transcript.ts already parses claude's own jsonl; the session identity usually lands within the turn — wait/poll briefly within the existing ask window rather than giving up immediately), persist THAT as the chat turn, and only fall back to a deflection turn when the transcript truly cannot be resolved by the deadline — and even then the fallback must include what IS known (that the terminal is processing) and render the Terminal tab reference as an actionable open-terminal action via the kage-actions mechanism, not just prose; (2) run pty-extracted reply text through the SAME kage-actions fence parser the headless legs now use (parse, strip, persist turn.actions) so chips ride terminal-answered threads identically; (3) tests: a stubbed pty leg whose transcript contains a reply with a kage-actions block yields a chat turn with text stripped and actions persisted; the deflection fallback only fires when the transcript is unresolvable and carries the open-terminal action. Do not change pty spawning or attach semantics; suite green; template-literal constraints where client files are touched; cite files individually.

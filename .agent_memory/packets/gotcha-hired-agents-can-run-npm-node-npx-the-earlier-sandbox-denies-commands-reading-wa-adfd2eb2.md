# Hired agents can run npm/node/npx — the earlier "sandbox denies commands" reading was a missing --allowedTools

> Hired agents CAN execute shell commands, including npm run test prefix mcp , npx tsc and node e . An earlier packet r…

Hired agents CAN execute shell commands, including `npm run test --prefix mcp`, `npx tsc` and `node -e`. An earlier packet recorded the opposite — that this sandbox's command-approval denies them — and that reading was wrong about the cause. The agents were spawned with acceptEdits but WITHOUT an explicit --allowedTools grant, and a headless claude session with no allowlist and no interactive permission dialog denies Bash silently. From inside the agent that is indistinguishable from a sandbox policy denial, which is why it was mis-recorded. Once the spawn passed --allowedTools, commands ran normally. Do not brief agents to skip verification on the belief that commands are unavailable; require them to run the checks for real.

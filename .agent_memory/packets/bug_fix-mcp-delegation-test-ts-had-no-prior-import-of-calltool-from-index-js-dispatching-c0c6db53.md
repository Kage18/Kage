# mcp/delegation.test.ts had no prior import of callTool from ./index.js — dispatching th...

> mcp/delegation.test.ts had no prior import of callTool from ./index.js — dispatching through the actual MCP tool hand…

mcp/delegation.test.ts had no prior import of callTool from ./index.js — dispatching through the actual MCP tool handler (not just dispatchRun directly) required adding that import, since kage_dispatch's goal-attachment logic lives in mcp/index.ts's runDelegationTool, not in dispatch.ts.

Learned while delivering: Close the last stitch in the Goals orchestration loop: the manager cannot attach its dispatched runs to a goal. The kage_dispatch MCP tool (defined around mcp/index.ts:1185) has no goal_id in its input schema, so when the Room manager orchestrates a goal (its constitution in mcp/delegation/manager-prompt.ts already instructs wave dispatch), the runs it creates never reach attachRunToGoal in mcp/delegation/goal.ts — and the event bridge in room-supervisor.ts (which wakes the manager only for goal-owned runs) never fires for them: the loop cannot close. Fix: (1) add an optional goal_id string property to the kage_dispatch tool schema with a one-line description (attach this run to an orchestrated goal so its state changes wake you); (2) in the tool handler, after the run is created, call attachRunToGoal(projectDir, goal_id, runId) when goal_id is present — tolerate an unknown goal id by returning the dispatch result with a plain warning string rather than failing the dispatch (the run is already real); (3) in manager-prompt.ts orchestrator section, add one sentence: when dispatching a wave for a goal, pass the goal id as goal_id on every kage_dispatch so the kernel wakes you as those runs change state. (4) Tests: extend the existing kage_dispatch tool test (find it in the mcp test files) or the goal tests to assert a dispatch with goal_id lands in the goal record run_ids and goalForRun resolves it; unknown goal_id warns without failing. Keep the diff tight. Success = npm test fully green.
Verified by: npm test --prefix mcp, diff-size, citations

# V0 delegation layer: manager on kernel, verification by execution

> Kage V0 is a delegation layer built as manager on kernel under mcp/delegation/ nothing added to kernel.ts — strangler…

Kage V0 is a delegation layer built as manager-on-kernel under mcp/delegation/ (nothing added to kernel.ts — strangler rule). The KERNEL owns guarantees: contract.ts holds the run state machine (draft→briefed→dispatched→running→verifying→ready|blocked|stopped|failed, then ready→merged|rejected; failed→running|rejected for retry) and is the only writer of task.json, so illegal transitions throw rather than being discouraged. verify.ts is the moat: it re-executes every check in the run worktree and takes the exit code as the verdict, writing evidence/<check>.log — an agent claiming "tests pass" over a red suite is caught by construction, and a command that cannot run returns unverified_no_env which never counts as a pass. The MANAGER is rented: manager-prompt.ts is a constitution appended to whatever coding agent the user has (buildRoomLaunch), it is stateless over kernel state (must call kage_room_state first), and its 10 MCP tools are gated behind KAGE_ROOM=1 so normal sessions do not see orchestration verbs. brief.ts compiles memory into every dispatch with real git-blame attribution (author + date), which is the felt-memory surface no competitor has. ratify.ts implements merge-ratification: learnings are written into the WORKTREE packet store as status pending (tracked file, so they ride the run branch and are reviewed with the code), and kage merge flips them to approved — merging the work is what promotes the memory. Rejection captures the reason as a negative_result packet. Adapters are thin CLI drivers (claude -p stream-json, codex exec, plus a stub for CI where no subscription exists); parseReportFence implements kage-claim-v1 with last-fence-wins and degrades to a protocol_ok:false skeleton claim rather than crashing.
Verified by: npm test: 398 unit + 12 dogfood pass; live loop on a scratch repo (brief carries attributed memory, planted lie caught by npm test exit code, merge ratified 1 learning, next brief carried it)

DEFECT 1, flicker: renderRoom() rebuilds the entire turn column on every SSE streaming delta (the room SSE handler does state.roomStreaming.push then renderRoom per token), on every 15s refreshRoom poll, and on every 30s refresh; each rebuild replays the .turn turnin CSS animation on every existing turn, so the whole chat shimmers continuously. Fix: (a) the SSE delta handler must NOT call renderRoom — update only the typing indicator elements (room-typing / room-typing-text) directly; (b) renderRoom skips the rebuild entirely when nothing changed — keep a cheap signature (turns.length, last turn text length, busy flag, linked-run count) and return early when it matches; (c) the entry animation plays only for turns never painted before — track the previously painted turn count and add the animated class only to turns at or beyond it (a plain class toggle; existing turns render with no animation). DEFECT 2, raw markdown: the manager speaks markdown but turns render as plain text, so users see literal ** and backticks. Build a tiny SAFE renderer used for kage turns only: bold segments (**text**), inline code (backtick text), and blank-line paragraph breaks, implemented by SPLITTING the string and appending createElement(strong)/createElement(code)/text nodes — absolutely no innerHTML, no regex. User turns stay plain text. Style the inline code with the existing mono/code tokens. DEFECT 3, no cards: the kernel redaction guard tells users to read the card, not the summary, but the Room renders no cards — the pointer dangles. After each kage turn, scan that turn text for run ids by splitting on whitespace/punctuation and matching tokens against state.runs ids (ids look like fix-the-packaged-desktop-app-failing-to-260817-e11e); for each distinct matched run render a compact inline run card under the turn: state glyph and display_state chip, intent, and when present claim-summary/checks atoms and cost via the existing costLabel — kernel facts only, click opens the run via openRun. Reuse existing classes where sensible and add new ones to app-styles.ts (they must appear in markup or client or the orphan-class gate fails). Also add one honesty gate to mcp/delegation-api.test.ts: assert the composed client script never contains the string innerHTML. Success = npm test fully green." was rejected.

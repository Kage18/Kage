> mcp/delegation/app client.ts and app styles.ts are TS template literals; the existing convention for any backslash me…

mcp/delegation/app-client.ts and app-styles.ts are TS template literals; the existing convention for any backslash meant to reach the browser as part of a regex is to write it doubled in the TS source (e.g. \\s+, \\r?\\n) — confirmed by grepping existing uses like the \\d+\\s*\\/\\s*\\d+ regex at the old line ~1443 and the delims array's \\n/\\t entries.

Learned while delivering: The app uses a run's raw intent as its display title everywhere, uncapped, so a well-written intent destroys the layout. Give every surface one short derived title.

MEASURED EVIDENCE (taken live from the running app at 127.0.0.1:3111/app just now, not guessed):
- '#run-detail .dhead' renders an <h2> containing 3,215 characters and measures 946px tall inside a 606px detail pane. The header alone is 1.5x the whole pane, so the activity body, the steer composer, and the entire action bar (Stop / Interrupt / Take Over / Reject) are ALL pushed below the fold. A user cannot reach a run's controls without scrolling past a wall of prose.
- Work list rows carry title text of 3177, 2551, 768 and 1382 characters with computed 'webkit-line-clamp: none'. They only look bounded because of fixed height plus overflow, and '.wrow' reports real horizontal overflow (scrollWidth > clientWidth).

This is a release blocker for the product's own advice: the New-run modal asks for 'What should change, and how you'll know it worked', so a GOOD intent is necessarily long — and the better the user writes, the worse the UI gets.

WHAT TO BUILD:
1. In mcp/delegation/contract.ts (next to runTag, which is the existing home for small shared run helpers), add and export `runTitle(run: TaskRecord): string`. It derives a SHORT display title from run.intent: take the first sentence or first line, trim trailing punctuation/colon, collapse whitespace, and cap at 96 characters on a word boundary with a single-character ellipsis. Never return an empty string — fall back to the run id if the intent is blank. Pure function, no I/O.
2. Use it in mcp/delegation/app-client.ts EVERYWHERE a run is named: the work list row (workRow), the detail header, the board card, the command palette entry, the goal card's run lines, and any notification text. Grep app-client.ts for '.intent' and route every display use through runTitle. Do not change what is SENT to the kernel — only what is displayed.
3. The full intent must stay reachable: in the detail pane, put it under a collapsed disclosure labelled 'Full intent' directly below the header, using the same fold pattern the transcript already uses. Default collapsed.
4. Belt and braces in mcp/delegation/app-styles.ts: give the row title and the detail h2 'overflow-wrap:anywhere' and a line-clamp (2 lines for a row, 3 for the header) so even a single 400-character unbroken sentence can never blow up the layout again.

CONSTRAINTS — READ THESE, THEY HAVE BROKEN RUNS BEFORE:
- app-client.ts and app-styles.ts are TypeScript TEMPLATE LITERALS compiled into a string. Every client-side escape must be DOUBLED: write \\n where the browser should see \n. A bare newline escape kills the whole page at parse time and every test still passes. No backticks and no ${ } inside them. Never use innerHTML.
- This project compiles to CommonJS. No 'import.meta' (TS1470), no top-level await.
- Put your tests in mcp/delegation-api.test.ts, NOT mcp/delegation.test.ts. Renderer and composed-page gates live in delegation-api.test.ts; another run is appending to delegation.test.ts right now and touching it will cause a merge conflict.

HOW YOU'LL KNOW IT WORKED — add tests to mcp/delegation-api.test.ts:
(a) runTitle caps a 3000-character intent at <= 96 chars, ends with the ellipsis, and breaks on a word boundary;
(b) runTitle on a short single-line intent returns it unchanged with no ellipsis;
(c) runTitle on an empty intent returns the run id;
(d) the composed page still parses (the existing 'emitted client script is syntactically valid' gate must stay green — run it);
(e) no raw '.intent' remains as a display value in a row or header render path.
Then run `npm test --prefix mcp` — the whole suite must stay green (627 tests before your change).
Verified by: npm test --prefix mcp, diff-size, citations

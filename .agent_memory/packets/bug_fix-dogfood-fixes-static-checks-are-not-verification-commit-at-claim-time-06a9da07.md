# Dogfood fixes: static checks are not verification; commit at claim time

> Kage first real self hosted delegation run exposed four defects, all fixed. 1 A claim passing only static checks rend…

Kage first real self-hosted delegation run exposed four defects, all fixed. (1) A claim passing only static checks rendered as VERIFIED 2/2 — the exact overclaim this product exists to prevent. claimVerdict in mcp/delegation/verify.ts now separates executed from inspected: with no command check it renders UNVERIFIED — nothing was executed, and the card says to configure a test command. (2) resolveTestCommand only probed the repo root, but this repo keeps package.json under mcp/ — it now probes common nested dirs and resolves npm test --prefix mcp. (3) Runs branch from HEAD, so uncommitted work is invisible to the hired agent and collides at merge: dirtyTreeWarning warns at dispatch and mergeRun in mcp/delegation/ratify.ts refuses when branch files overlap the reviewer uncommitted paths. GOTCHA: the git helper trims stdout, which eats the leading space of git status --porcelain, so a fixed-column slice silently yielded rc/retry.ts instead of src/retry.ts — dirtyPaths now parses by shape and unquotes spaced paths. (4) commitWorktree ran only inside the merge, so during review the branch had zero commits and git merge reported Already up to date over 66 lines of real work; the commit now happens at claim time so a pushable branch exists before any decision. Added live progress in mcp/delegation/progress.ts: the cli-agent adapter parses stream-json into structured tool events, dispatch renders a self-rewriting TTY line with milestone lines when piped, and kage status --watch renders a board reading current activity from transcripts. Also tightened the phantom-symbol capture gate in mcp/kernel.ts: a strong identifier now needs an INTERNAL capital, because the old pattern flagged ordinary capitalized prose words.
Verified by: npm test --prefix mcp: 405 unit + 12 dogfood pass; re-rendered the real room run claim as UNVERIFIED; resolveTestCommand('.') returns npm test --prefix mcp

# Manager judgment is recorded, kernel-validated, and measured against outcomes

> The manager agent shaped briefs invisibly: its curation existed only as prose in the constitution, leaving no trace, …

The manager agent shaped briefs invisibly: its curation existed only as prose in the constitution, leaving no trace, which by Kage own rule means it did not happen. Now every dispatch records a judgment in the run directory as manager.json, and each run carries a curated_by field of manager or kernel so the two are never confused. The kernel does not trust what the manager hands it: a dropped memory must be one that was actually offered, every drop needs a reason, and confidence may only be lowered because that number is what a human uses to decide how closely to look. Refused moves are not silently ignored, they are stored in a violations list and shown in the receipt, so an agent that tries to inflate its own confidence leaves evidence. The payoff is measurement: curationComparison in mcp/delegation/trackrecord.ts splits verified-first-try rates by who shaped the brief, and renderCurationLine deliberately refuses to draw a conclusion under five runs per side, printing collecting instead. This makes the agentic layer falsifiable — if manager curation does not beat kernel defaults on real runs, the honest move is to cut it rather than carry it. The constitution now tells the manager that its judgment is measured and that curating to look busy shows up as a worse outcome.
Verified by: npm test --prefix mcp: 425 unit + 12 dogfood pass; live run showed an invented drop and a confidence inflation both refused and recorded

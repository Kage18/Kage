# The agent stream has THREE consumers — usage capture must live in every one

> Cost/token capture usageFrom in mcp/delegation/adapters/cli agent.ts, parsing claude's result event: total cost usd +…

Cost/token capture (usageFrom in mcp/delegation/adapters/cli-agent.ts, parsing claude's result event: total_cost_usd + usage including cache_read_input_tokens/cache_creation_input_tokens) had to be wired into every consumer of the agent's stdout stream, and there are three: (1) cliAgent.run's line loop — foreground dispatch and the supervisor's no-live-stdin fallback; (2) the supervisor's held-stdin live loop in supervisor.ts (~line 240) — the path real detached runs actually take, with its own independent line parser; (3) the room supervisor's loop in room-supervisor.ts. Patching cli-agent alone passed all tests while a real run still recorded spend 0, exactly like the buildClaim two-writer drift — the tested path is never the real path.

recordSpend() in contract.ts is the single writer for spend (both execution paths call it), computes minutes from the running transition in state_history, rounds usd to 4dp, and NEVER invents: absent usage leaves spend at its untouched default rather than writing zeros that read as "measured free". TaskRecord gained tokens_used?: number.

Token totals must include cache fields: a live run reported $0.1866 with input+output = 619 tokens — the other 208k were cache reads/creation. Showing "619 tok · $0.19" reads as a contradiction; the total should explain the price (209,004 tok).

UI: costLabel() renders "$0.19 · 209k tok" as a header chip (title says "reported by the agent CLI") and the dollar figure on board cards. Absent when nothing was reported.
Evidence: Observed directly: after patching cli-agent only, a real held-stdin claude run's task.json still had spend {usd_est:0}; its transcript showed the result line logged as kind:"stdout" (unparsed) in the supervisor's own loop. After wiring the held loop: spend {"usd_est":0.1868,"minutes":0.3}, tokens_used 209004 on a real run, and "$0.19 · 209k tok" visible in the run header.
Verified by: npm test — 560 pass 0 fail exit 0, including usageFrom unit tests (cache tokens counted, non-result events rejected) and recordSpend never-invents tests

# A run can merge VERIFIED with an empty diff — verification proves the tree is green, not that promised content exists

> The reviewer goal's Wave 1 run merged reading VERIFIED 5/5, yet contributed ZERO content: its branch tip was an unrel…

The reviewer goal's Wave 1 run merged reading VERIFIED 5/5, yet contributed ZERO content: its branch tip was an unrelated ancestor commit (db368cd), so kage merge fast-forwarded nothing and the tree never gained mcp/delegation/review.ts or the review states its claim described. Every check passed honestly — the suite was green, the diff-size cap unexceeded (an empty diff is trivially under any cap), citations resolved (the cited files existed for other reasons or in the worktree). Nothing in verification asserts that a feature run's diff is NON-EMPTY, so "merged + verified" can be true of a no-op. The lie was discovered a day later only because Wave-2 agents checked the tree for the contract instead of trusting the goal record's "wave 1 merged", and blocked themselves. Derived wave/goal statuses inherit the same blindness: goalWaveStatus reads run states, so a content-empty merged run makes a wave read "merged" over nothing. Guard direction (not yet built): mergeRun should refuse a feature/bugfix/refactor run whose branch adds no commits beyond the merge-base (the same zero-commit signal branch_landed now checks), or at minimum the receipt must lead with "EMPTY DIFF" so a human cannot miss it.
Evidence: git merge-base --is-ancestor kage/add-a-reviewer-agent-role-to-kage-s-run-260819-9683 release-prep returns yes with the branch tip at db368cd ("app: alt-Enter must not vanish", 2026-08-19), an unrelated commit; ls mcp/delegation/review.ts → missing; grep for the review states in contract.ts → 0; the run's record shows merged with a VERIFIED receipt. Both Wave-2 runs (adapters-…-41d2, surface-…-01e9) independently blocked with "Wave 1 kernel contract missing".
Verified by: Direct tree inspection vs the run record, 2026-08-21; two independent agents reached the same conclusion from the tree

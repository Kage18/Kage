# kage ui: dependency-free TUI with a pure render/reducer core

> kage ui is a full screen terminal console for delegation Board, Review, Dispatch, Memory built with zero new dependen…

kage ui is a full-screen terminal console for delegation (Board, Review, Dispatch, Memory) built with zero new dependencies — raw ANSI plus stdin raw mode. The architecture that makes a TUI testable: a PURE core and a thin imperative shell. state.ts holds a reducer, key plus state to state plus effect, so every interaction is asserted without a terminal; render.ts holds pure functions from state to lines, so every screen is asserted as text; app.ts is the only file that touches the terminal or performs effects. Tests in mcp/tui.test.ts call setColorEnabled false and assert on stripAnsi output, and one test proves frames never exceed the viewport at 40x12. Key design rules learned while building: text-entry modes must swallow printable keys BEFORE global shortcuts or typing a search query fires merge or quit; a paste arrives as one multi-character chunk so input splits chunks unless they start with escape; dispatch from the UI is fire-and-forget because the kernel persists state, and blocking the loop on an agent would freeze the console for minutes; combined ANSI styles emit a single sequence like 93;1m so tests must not assert on a bare colour code. Also fixed here: ensureDelegationIgnores in mcp/delegation/contract.ts now covers every derived store, not just runs and worktrees, because a worktree capture writes audit and index files that were landing in run commits and polluting the review diff.
Verified by: npm test --prefix mcp: 415 unit + 12 dogfood pass; rendered real Board/Review/Memory/Dispatch frames from the demo repo

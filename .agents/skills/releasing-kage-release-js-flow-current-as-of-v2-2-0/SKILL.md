# Releasing Kage: release.js flow current as of v2.2.0

node dist/release.js publish push smoke from mcp/ publishes from any named branch incl. master : preflights clean worktree, fetches+pushes the branch rebase first if the kage sync bot raced you — it pushes skip ci commit

node dist/release.js --publish --push --smoke from mcp/ publishes from any named branch (incl. master): preflights clean worktree, fetches+pushes the branch (rebase first if the kage-sync bot raced you — it pushes [skip ci] commits to master frequently), npm publish with public access, verifies version, smoke-installs the published package. Then: mcp-publisher login http -domain kage-core.com -private-key $(tr -d '[:space:]' < /tmp/mcp-pub/priv.hex) and mcp-publisher publish (server.json must have BOTH version fields bumped; JWTs expire in hours). Finally upgrade the vendored copy: cp -R mcp/dist/* ~/.Codex/kage-mcp/dist/ + package.json (launcher pins it via --mcp-config).

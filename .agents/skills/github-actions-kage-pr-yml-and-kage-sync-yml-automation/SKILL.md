## Detail

Two GitHub Actions workflows automate kage memory maintenance. kage-pr.yml fires on every PR — builds kage CLI, runs quality + pr check, posts a memory health comment via gh. kage-sync.yml fires on every merge to master — runs kage refresh (rebuilds code graph, knowledge graph, indexes), kage propose --from-diff (captures change memory), and auto-deprecates stale packets with no helpful votes, then commits updated .agent_memory/ back with [skip ci]. kage-pr.yml requires id-token: write permission for Codex OAuth token exchange. Workflow files must be identical on PR branch and master for the OAuth flow to work.
